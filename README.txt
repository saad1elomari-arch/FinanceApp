MON ARGENT — VERSION IPHONE LOCALE

Cette version est conçue pour un seul iPhone :
- aucune connexion cloud
- aucun compte
- aucune dépendance externe
- données enregistrées localement dans le navigateur/app
- cache PWA pour ouvrir l'application hors connexion après la première visite
- export JSON pour sauvegarde
- import JSON pour restauration

INSTALLATION SUR IPHONE
1. Publier le dossier finance_app sur un hébergement HTTPS.
2. Ouvrir l'adresse dans Safari sur l'iPhone.
3. Attendre que la page se charge une première fois avec Internet afin que le cache soit installé.
4. Safari > Partager > Ajouter à l'écran d'accueil.
5. Ouvrir ensuite Mon Argent depuis l'icône de l'écran d'accueil.

SAUVEGARDE
Dans Mon Argent > Données > Exporter mes données.
Conserve le fichier mon-argent-sauvegarde.json dans un emplacement sûr.

RESTAURATION
Dans Mon Argent > Données > choisir le fichier JSON exporté.
L'import remplace les données actuellement présentes.

IMPORTANT
Les données ne sont pas synchronisées avec un autre appareil. Si le site est supprimé des données Safari ou si l'iPhone est réinitialisé, les données locales peuvent être perdues. Fais régulièrement un export JSON.
